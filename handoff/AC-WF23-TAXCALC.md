## 1. 🔴 ของที่กระทบทางนั้นมากที่สุด — **field ID ในเอกสารตายไป 28 ตัว และทุกตัวเป็นฟิลด์ตัวเลือก**

เทียบ field ID ทุกตัวในตารางฟิลด์ของ `14-FRS-Modules-AC.md` (**456 ตัว**) กับฟิลด์สดของ 40 ตารางบนเซิร์ฟเวอร์ ⇒ **ตายแล้ว 28 ตัว · ทุกตัวเป็น Dropdown / SingleSelect / MultipleSelect ไม่มีชนิดอื่นเลยสักตัว**

**สาเหตุร่วม:** ฟิลด์ตัวเลือกทั้งชุดถูก **ลบแล้วสร้างใหม่** ตอนรอบผูก shared optionset / ตั้งชื่อไทย ⇒ ID ใหม่ทั้งชุด แต่เอกสารยังถือ ID ก่อนรอบนั้น

⇒ **ฝั่ง HR ทำรอบตั้งชื่อไทย/ผูก optionset เหมือนกัน — ขอให้รันเช็คเดียวกัน** สคริปต์คือ: ดึง field ID สดของทุกตาราง → เทียบกับ ID ที่อยู่ในตารางฟิลด์ของเอกสาร → ตัวที่ไม่อยู่ในชุดสด = ตาย
**เจอเพราะ** `validate_process` ฟ้อง `StartNodeControlsIsNull` ตอนสร้าง node · ⚠️ **แต่ validate จับได้เฉพาะบางตำแหน่ง** — ถ้า ID ตายไปโผล่ในที่ที่ validate ไม่ตรวจ จะได้ workflow ที่เขียนลงที่ที่ไม่มีอยู่โดยไม่มีใครรู้

🔴 **กฎที่ขอให้ยึดร่วมกัน: ก่อนสร้าง node ทุกครั้ง ดึงฟิลด์สดของตารางนั้นมาเทียบ ID ก่อน — โดยเฉพาะฟิลด์ตัวเลือก**
