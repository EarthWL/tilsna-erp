# 23 — ตรวจและแก้ค่าที่ยังเป็นภาษาจีน/ค่า default: รูปแบบวันที่ · ชื่อ View · ชื่อเรียกระเบียน

**งาน** `AC/I18N-DATE-VIEW` · **agent-ac** · 6 ก.ย. 2569
**ขอบเขต** ทุก worksheet ใต้ section `บัญชี (AC)` = 47 ตาราง (AC-00 … AC-07) · ไม่แตะ HR

---

## 1. วิธีตรวจ (ทำซ้ำได้)

CLI `hap` ไม่คืนค่า `advancedSetting` ของฟิลด์ (ผลลัพธ์ถูกย่อ) และ MCP ก็ไม่คืน `entityName`
จึงเรียก **internal API ผ่าน SDK ของ hap-cli** ตรง ๆ:

```python
from hap_cli.core.session import Session
from hap_cli.core import worksheet as W
S = Session.load()                       # cloud sandbox ของ agent auth ไว้แล้ว
d = W.get_worksheet_info(S, wid, app_id=APP, get_template=True, get_views=True)
d['entityName']                          # ชื่อเรียกระเบียน
d['views'][i]['name']                    # ชื่อ view
d['template']['controls'][i]['advancedSetting']['showformat']   # รูปแบบวันที่
```

สคริปต์ที่ใช้จริงอยู่ใน scratchpad ของ session (`i18n/scan.py`, `i18n/fixdate.py`) — ตรรกะสรุปไว้ในไฟล์นี้ทั้งหมด

## 2. สิ่งที่พบ

| ประเด็น | จำนวน | อยู่ที่ไหน |
|---|---|---|
| ชื่อเรียกระเบียน (`entityName`) = `记录` | 7 | ทุกตารางใน **AC-05 ลูกหนี้และรายได้** |
| ชื่อ view เริ่มต้น = `全部` | 7 | ทุกตารางใน **AC-05** |
| ฟิลด์วันที่ไม่ได้ตั้งรูปแบบ (`showformat: "1"` = ค่าโรงงาน → แสดง `YYYY-MM-DD`) | 12 | AC-05 ทั้ง 10 ฟิลด์ + `พารามิเตอร์ระบบบัญชี` 2 ฟิลด์ |
| `entityName` เป็นไทยแต่ผิดรูป (`เพิ่มพารามิเตอร์` → ปุ่มขึ้นว่า "เพิ่มเพิ่มพารามิเตอร์") | 1 | AC-00 พารามิเตอร์ระบบบัญชี |
| ชื่อฟิลด์ / ตัวเลือก / hint / คำอธิบายตาราง เป็นภาษาจีน | **0** | — สแกนครบทั้ง 47 ตารางแล้ว |

**สาเหตุ:** ตารางที่สร้างผ่าน **MCP `create_worksheet`** จะได้ `entityName = 记录`, view เริ่มต้นชื่อ `全部`
และฟิลด์ Date ที่ไม่ระบุ `config.format` จะได้ `showformat: "1"` + `showtype: ""` (ไม่กำหนดความละเอียด)
ตารางที่สร้างสมัยแรก ๆ ผ่าน CLI/UI ไม่มีอาการนี้ — ทั้ง AC-00…AC-04 และ AC-07 สะอาดหมด

## 3. ค่ามาตรฐานของโมดูล AC (ยึดจากของเดิม ไม่ได้ตั้งใหม่)

| ชนิดฟิลด์ | `showformat` | `showtype` / `unit` | `enumDefault` |
|---|---|---|---|
| Date (type 15) | `DD/MM/YYYY` | `3` (ปี-เดือน-วัน) | `3` |
| DateTime (type 16) | `DD/MM/YYYY HH:mm` | `1` (ปี-เดือน-วัน-ชม.-นาที) | `1` |

ก่อนแก้มี 26 + 6 ฟิลด์ที่ใช้ค่านี้อยู่แล้ว ⇒ เป็นมาตรฐานที่มีอยู่จริง ไม่ใช่การตัดสินใจใหม่

**ชื่อเรียกระเบียน** = ชื่อตารางแบบสั้น (ตัดวงเล็บออก) · **view เริ่มต้น** = `ทั้งหมด` — ตรงกับ 40 ตารางที่เหลือ

## 4. สิ่งที่แก้

### 4.1 ชื่อ view (7 รายการ) — `hap worksheet view update <wid> <vid> --name "ทั้งหมด"`

`全部` → `ทั้งหมด` ที่ ใบแจ้งหนี้ลูกหนี้ · รายการรายได้ · ใบกำกับภาษี/ใบส่งของ · ใบเสร็จรับเงิน · ใบลดหนี้ · ใบเพิ่มหนี้ · ใบวางบิล

### 4.2 ชื่อเรียกระเบียน (8 รายการ)

🔵 **API ที่ใช้ได้คือ `Worksheet/UpdateEntityName`** — `{worksheetId, appId, entityName}`
(ลองแล้วไม่ได้: `Worksheet/EditWorksheetSetting` → *Service exception* · `Worksheet/UpdateWorksheetName` → 404)
CLI และ MCP **ไม่มี** คำสั่งสำหรับค่านี้

| ตาราง | ก่อน | หลัง |
|---|---|---|
| ใบแจ้งหนี้ลูกหนี้ | 记录 | ใบแจ้งหนี้ลูกหนี้ |
| รายการรายได้ | 记录 | รายการรายได้ |
| ใบกำกับภาษี / ใบส่งของ | 记录 | ใบกำกับภาษี / ใบส่งของ |
| ใบเสร็จรับเงิน | 记录 | ใบเสร็จรับเงิน |
| ใบลดหนี้ | 记录 | ใบลดหนี้ |
| ใบเพิ่มหนี้ | 记录 | ใบเพิ่มหนี้ |
| ใบวางบิล | 记录 | ใบวางบิล |
| พารามิเตอร์ระบบบัญชี | เพิ่มพารามิเตอร์ | พารามิเตอร์ระบบบัญชี |

### 4.3 รูปแบบวันที่ (12 ฟิลด์) — `Worksheet/SaveWorksheetControls`

อ่าน controls ทั้งชุด → แก้เฉพาะ `advancedSetting.showformat` / `showtype` / `unit` / `enumDefault` ของฟิลด์เป้าหมาย → เขียนกลับทั้งชุด
(`editAttrs: ["advancedSetting","unit","enumDefault"]`) · **ไม่แตะฟิลด์อื่นและไม่แตะข้อมูลในระเบียน**

| ตาราง | ฟิลด์ |
|---|---|
| พารามิเตอร์ระบบบัญชี | วันตัดยอดข้อมูล · วันขึ้นระบบจริง |
| ใบแจ้งหนี้ลูกหนี้ | วันที่เอกสาร · วันครบกำหนดชำระ · (ระบบ) เวลาที่รับรู้รายได้ *(DateTime)* |
| ใบกำกับภาษี / ใบส่งของ | วันที่ใบกำกับภาษี · วันที่ความรับผิดทางภาษี (tax point) |
| ใบเสร็จรับเงิน | วันที่รับเงิน |
| ใบลดหนี้ | วันที่ใบลดหนี้ |
| ใบเพิ่มหนี้ | วันที่ใบเพิ่มหนี้ |
| ใบวางบิล | วันที่วางบิล · วันนัดรับเช็ค |

## 5. ผลตรวจหลังแก้ (ยิงสแกนซ้ำทั้ง 47 ตาราง)

```
ค้างเป็นภาษาจีน / ค่า default : 0
รูปแบบวันที่ทั้งโมดูล AC      : 37 × DD/MM/YYYY (Date) + 7 × DD/MM/YYYY HH:mm (DateTime)
จำนวนฟิลด์ก่อน/หลัง 7 ตารางที่แก้ : 22/22 · 19/19 · 46/46 · 34/34 · 29/29 · 25/25 · 25/25  ✓ ไม่มีฟิลด์หาย
จำนวนระเบียน                  : GL 337 · ใบแจ้งหนี้ 32 · รายการรายได้ 43 · ใบกำกับภาษี 32 · ใบเสร็จ 22 · ใบสำคัญ 97
ค่าในระเบียน (doc_date/due_date) : คงเดิม — showformat คุมแค่การแสดงผล ไม่แตะค่าที่เก็บ
```

⚠️ **`count` ใน `GetWorksheetInfo` เป็นค่าแคช เชื่อไม่ได้** — คืน GL = 264 ทั้งที่ของจริง 337
ให้ใช้ `count` จาก `Worksheet/GetFilterRows` (`record.get_records(...)['count']`) แทน

📌 **แก้ตัวเลขที่เคยรายงานผิด:** ใบเสร็จรับเงินมี **22 ใบ** (RC-2569/0001–0022 ครบไม่ขาดช่วง) ไม่ใช่ 23 ตามที่เคยแจ้ง
