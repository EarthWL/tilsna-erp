## 5. 🔴🔴 กราฟบันทึกสำเร็จแต่ขึ้นว่างเปล่า — ต้องเปิดดูด้วยตาถึงจะรู้

`hap worksheet chart create` **ตอบ `reportId` กลับมาปกติทั้ง 14 อัน** และอ่าน config กลับมาก็เห็น `xaxes` / `yaxisList` / `filterId` ครบ
แต่พอเปิดหน้าแดชบอร์ดจริง **13 จาก 14 อันขึ้นว่าง** พร้อมข้อความ `Cannot generate the Chart — Components do not exist or deleted`

**สาเหตุ:** เมื่อส่ง `filter.items` (เงื่อนไขแบบ high-level) เข้าไป CLI จะบันทึก filter แล้วใส่ `filterId` ให้ — **แต่มันเขียนทับบล็อกขอบเขตเวลาทิ้ง** ผลคือ

```
พัง   : {"filterRangeId": null,   "today": true,  "filterId": "6a9d…", "dynamicFilter": null}
ปกติ  : {"filterRangeId": "ctime","today": false, "filterId": null,    "dynamicFilter": {…}}
```

อันที่รอดคือ `ยอดค้างจ่ายรวม` กับ `ยอดค้างจ่ายตามเจ้าหนี้` — สองอันเดียวที่**ไม่ได้ส่ง `filter.items`** ⇒ CLI เติมค่าเริ่มต้นให้เอง

**วิธีแก้:** อ่าน config กลับมา แล้ว merge บล็อกขอบเขตเข้าไปโดย**เก็บ `filterId` เดิมไว้** แล้วบันทึกกลับ

```python
f = cfg['filter']
f.update({"filterRangeId":"ctime","filterRangeName":"Creation time","rangeType":0,"rangeValue":None,
          "today":False,"ignoreToday":False,
          "dynamicFilter":{"startType":1,"startUnit":1,"startCount":1,"endType":1,"endUnit":1,"endCount":1},
          "startDate":"","endDate":"","customRangeValue":None})
chart.save_chart(S, report_id=rid, app_id=wid, name=name, report_type=rt, extra=cfg)
```

แก้ 12 อัน → เปิดดูอีกรอบ **ขึ้นครบทั้ง 14 อัน** ตัวเลขบนหน้าจอตรงกับที่คำนวณทุกตัว

🔑 **`report/getData` เรียกตรงไม่ได้** (ตอบ 500 ทุกรูปแบบ payload ที่ลอง) ⇒ **ไม่มีทางตรวจว่ากราฟขึ้นจริงไหมจาก API เลย ต้องเปิดหน้าเว็บดู** — บันทึกเป็น **D-54**

## 6. เรื่องอื่นที่พบระหว่างทาง

- **`hap worksheet create --fields` ทิ้ง `alias` และ `config.format`** — ฟิลด์ถูกสร้างถูกชนิดหมด แต่ alias ว่างทุกตัว และ Date/DateTime ได้ `showformat` ค่าโรงงาน ⇒ ต้องตามแก้ด้วย `SaveWorksheetControls` (**D-55**)
- **ตารางที่สร้างผ่าน CLI ได้ `entityName = "Record"` และ view ชื่อ `"All"`** (ภาษาอังกฤษ) — คนละอาการกับ MCP ที่ได้ `记录` / `全部` แต่ต้องตามแก้เหมือนกัน (ต่อยอด **D-50**)
- **`batch_create_rows(..., trigger_workflow=False)` ถูก CLI ปฏิเสธ** ไม่ใช่เพิกเฉย — ตารางที่ไม่มี workflow ให้ปล่อย `True` ไปเลย
- **✅ AC-R-18 ปิดได้แล้ว โดยไม่ต้องทำอะไร** — ตรวจของจริงพบว่า `AC_AP.ap_no` **มีค่าครบทั้ง 32 ใบ** `AP-2569/0001–0032` ไม่ซ้ำ ไม่ขาดช่วง (บันทึกใน `17-Pending-Human-Review-AC.md` ล้าสมัย)
