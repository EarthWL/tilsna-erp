## 2. วิธีที่ใช้ · เลี่ยงกับดัก D-54 ตั้งแต่ต้น

บทเรียน D-54 (กราฟบันทึกสำเร็จแต่ขึ้นว่าง) เกิดจากการส่ง `filter.items` เข้าไป แล้ว CLI เขียนทับบล็อกขอบเขตเวลาทิ้ง

**คราวนี้จึงไม่ส่ง `filter` เลยสักกราฟ** — CLI เติมขอบเขต "ทุกช่วงเวลา" ให้เอง (`_DEFAULT_CHART_FILTER`) ⇒ ทั้ง 17 กราฟขึ้นครบตั้งแต่รอบแรก ไม่ต้องตามแก้

การจำกัดขอบเขตที่ต้องการ ทำด้วยการ**เลือกตารางต้นทางให้ถูก**แทน เช่น ยอดค้างรับใช้ตารางใบแจ้งหนี้ทั้งหมด (ใบที่ชำระครบแล้วมียอดคงค้าง 0 อยู่แล้ว รวมมาก็ไม่กระทบ)

```python
# สร้างกราฟ
hap --json worksheet chart create <WS_ID> --name <ชื่อ> --report-type <1|3|10|16> -j '{
  "xaxes": {"controlId": "<field>", "controlType": 29},
  "yaxisList": [{"controlId": "<amount>", "controlType": 6, "normType": 1}]
}'
# วางลงหน้า
page.save_page(S, pageId, version=<version ปัจจุบัน>, components=[...], owner_app_id=APP)
```

**กราฟแยกสี (split)** ใช้ที่ "ยอดค้างตามช่วงอายุหนี้" — ต้องใส่ **ทั้ง `split.controlId` และ `splitId`** มิฉะนั้นการแยกสีจะถูกล้างทิ้งเงียบ ๆ ตอนบันทึก

## 4. ข้อสังเกตที่ยังไม่แก้

- **กราฟ "จำนวนภาษีตามประเภทเอกสารต้นทาง" แสดงป้ายเป็น `AC_INV` / `AC_AP`** — เป็นค่าใน optionset `ประเภทเอกสารต้นทาง` ของทะเบียนภาษีที่ตั้งเป็นรหัสระบบ ไม่ใช่ภาษาไทย ⇒ **AC-R-42** (ไม่แก้เองเพราะ optionset อาจถูกอ้างในที่อื่น ต้องตรวจก่อน)
- **กราฟทุกตัวเป็นภาพสด อ่านจากตารางต้นทางโดยตรง** ไม่เหมือนงบการเงิน/รายงานอายุหนี้ที่เป็นภาพนิ่ง ⇒ ข้อมูลเปลี่ยนกราฟขยับเอง
- **ยังไม่มีแดชบอร์ดให้ AC-07 ปิดบัญชีและกระทบยอด และ AC-08 เชื่อมต่อระบบ** — ข้อมูลยังน้อย (1–21 แถว) กราฟจะดูบางเกินไป
