## ทำไมไม่ใช้ print template ของแพลตฟอร์ม

ตรวจแล้วทั้งสองพื้นผิว (2 ก.ย. 2569):

- **MCP** ไม่มี tool ใดเกี่ยวกับ print / template และ node **"พิมพ์เอกสาร (Print Record)"** อยู่ในกลุ่มที่ MCP สร้างไม่ได้
- **`hap` CLI 0.8.22** — `hap --help` ไม่มี subcommand print หรือ template เลย

⇒ print template ตั้งค่าได้เฉพาะบน Browser · ยังควรทำเพิ่มในอนาคตเพื่อให้ผู้ใช้กดปุ่ม "พิมพ์" เองได้
(เส้นทางนี้ให้ผลเป็น batch เท่านั้น)

## ข้อจำกัดที่เหลือ

1. **ไม่มีข้อมูลกิจการ** (AC-R-19) — บล็อกการใช้จริง เพราะหนังสือรับรองที่ไม่มีชื่อและเลขผู้เสียภาษีของผู้จ่ายใช้ไม่ได้
2. **ไม่มีลายเซ็น / ตราประทับ** — เว้นที่ไว้ให้เซ็นมือ
3. **ไม่ได้แตะ `สถานะหนังสือรับรอง`** — ทั้ง 8 ใบเป็น "รวมในการยื่นแบบแล้ว" อยู่แล้ว ซึ่งเป็นสถานะที่ไกลกว่า "พิมพ์แล้ว" จึงไม่เขียนทับ
4. **ไม่ได้ตั้ง `ผู้พิมพ์`** — เป็นฟิลด์ Collaborator ถ้าใส่คนจริงจะเป็นการกุข้อมูล ให้ workflow หรือผู้ใช้จริงเป็นคนเขียน
5. **ยังเป็น batch** — ยังไม่มี workflow ที่ออกไฟล์ให้อัตโนมัติเมื่อสร้างหนังสือรับรองใหม่
