## สภาพจริงบนเซิร์ฟเวอร์ (ยืนยันเมื่อ 26 ส.ค. 2569)

**มีแล้ว**

- **34 worksheet** ใน 5 กลุ่ม: ตั้งค่า (7) · ข้อมูลหลัก (15) · บัญชีแยกประเภท (3) · เจ้าหนี้และการจ่าย (7) · ภาษี (2)
- **30 optionset** — แต่ **9 ชุดยังไม่มีฟิลด์ใดผูก** (นี่คือรายการฟิลด์สถานะที่ยังต้องสร้าง)
- **8 custom role** พร้อม ID และคำอธิบายภาษาไทย — แต่ **ไม่มีสมาชิกเลยสักคน**
- ข้อมูล: ผังบัญชี 79 · งวดบัญชี 13 · คู่ค้า 30 · อัตรา VAT 5 · ใบสำคัญทดสอบ 4 · เจ้าหนี้ 0

**ยังไม่มี**

- ⬜ **workflow — ศูนย์ตัว** (`get_workflow_list` ว่าง และ log มีแต่ `user-api`)
- ⬜ **16 worksheet** — เอกสารขาย 7 · สินทรัพย์ 4 · ปิดงวด 3 · กระทบยอดธนาคาร 1 · GFMIS 1
- ⬜ ฟิลด์สถานะบนตารางธุรกรรมเกือบทุกตัว
- ⬜ Custom Action · View · Chart · Custom Page · การตั้งสิทธิ์จริง

## 5 เรื่องที่บล็อกทุกอย่างอยู่ตอนนี้

1. 🔴 **ไม่มีฟิลด์ `approver_user` (Collaborator) บนตารางใดเลย** ⇒ สร้าง Approve node ไม่ได้ ⇒ ไม่มีสายอนุมัติใดทำงานได้
2. 🔴 **`AC_APPROVAL_RULE.approver_role_*` เป็นชนิด OrgRole** — ยังไม่พิสูจน์ว่า Approve node รับค่าจากตรงนั้นได้ · **นี่คือ probe แรกที่ต้องทำ**
3. 🔴 **role ทั้ง 8 ไม่มีสมาชิก** ⇒ ทดสอบผู้จัดทำ ≠ ผู้อนุมัติไม่ได้ ⇒ พิสูจน์ทั้ง approval และการแยกหน้าที่ไม่ได้ · **ต้องขอบัญชีทดสอบอย่างน้อย 2 บัญชีจากผู้ใช้**
4. 🔴 **`AC_VAT_DOC` ขาด `vat_side` และ `claim_status`** ⇒ กลไกจุดความรับผิดทางภาษี ซึ่งเป็นเหตุผลหลักของ SDS v2.0 ยังทำงานไม่ได้เลย
5. 🔴 **ข้อสมมติ A-09 และ A-11 ยังไม่ได้คำตอบ** ⇒ ตัดสินว่าโมดูลจะใหญ่หรือเล็กลงราวหนึ่งในสาม

## สิ่งที่โครงสร้างเดิมทำไว้ดีแล้ว (อย่ารื้อ)

- **`AC_VOUCHER.total_debit` / `total_credit` เป็น Rollup และ `balance_diff` เป็น Formula** ⇒ ตรวจดุลได้ทันทีโดยไม่ต้องคำนวณใน workflow — **ห้ามแตะ Formula ตัวนี้**
- **`AC_VOUCHER.period_status_ref` เป็น Lookup ผ่าน `period`** ⇒ ตรวจสถานะงวดใน Branch node ได้เลย ไม่ต้อง Get Single Record
- **`AC_GL.movement_seq` เป็น AutoNumber** ⇒ ลำดับการเคลื่อนไหวต่อเนื่องตาม NFR-05 ได้ฟรี
- **`AC_VAT_DOC` แยก `tax_point_date` ออกจาก `tax_invoice_date`** และมีฟิลด์ `sign` สำหรับรายการติดลบ ⇒ โครงถูกต้องแล้ว เหลือแค่ฟิลด์สถานะ
- **`AC_PAY_LINE`** ซึ่งไม่มีใน SDS ⇒ เป็นตัวที่ทำให้จ่ายทีเดียวหลายคู่ค้าหลายเอกสารเป็นไปได้
- **`AC_AP_LINE.wht_rate` เป็น Number** (สำเนาอัตรา ไม่ใช่ lookup) ⇒ เอกสารเก่าคงอัตราที่ใช้ตอนนั้นไว้ถูกต้อง
