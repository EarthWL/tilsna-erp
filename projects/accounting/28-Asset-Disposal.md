## 5. บทเรียนใหม่ · ตัวกรองรับ label แต่การเขียนต้องใช้ key

WF-AC-21 รอบแรก **ล้างสถานะสินทรัพย์เป็นค่าว่าง** แทนที่จะตั้งเป็น "ตัดจำหน่ายแล้ว" — เพราะ node `updAsset` เขียนค่าเป็น **ข้อความ** `'ตัดจำหน่ายแล้ว'` ไม่ใช่ key

สิ่งที่ทำให้พลาดคือ **ตัวกรองของ trigger ที่ใช้ label เดียวกันกลับ match ได้ปกติ** ⇒ เข้าใจผิดว่าทั้งระบบรับ label

> 🔑 **ตัวกรอง (filter) รับ label ได้ · การเขียนค่า (write) ต้องใช้ key เสมอ** — บันทึกเป็น **D-62** ใน `MIGRATION.md`

แก้โดย **ลบ process ทั้งตัวแล้วสร้างใหม่** (node แก้ไม่ได้) ทดสอบซ้ำผ่าน

## 8. ภาคผนวก · แก้สกุลเงินจากหยวนเป็นบาท (6 ก.ย. 2569)

### อาการ

ฟิลด์ชนิด **Currency (type 8)** ที่สร้างผ่าน API ได้ค่าโรงงานเป็น `{"currencycode":"CNY","symbol":"¥"}`
⇒ ตัวเลขเงินทุกช่องขึ้น **¥ 58,000.00** แทนที่จะเป็น **฿ 58,000.00**

`hap worksheet fields` และ MCP **ไม่คืน `advancedSetting`** จึงมองไม่เห็นปัญหานี้จาก CLI — ต้องอ่านผ่าน SDK `GetWorksheetInfo` (ตาม D-50)

### ขอบเขตที่ตรวจ

สแกน **worksheet ทั้งแอป 98 ตาราง** (AC 57 · HR 41) ทุกฟิลด์ชนิด 6/8/25/31/37/38/53 ดูทั้ง `unit` · `advancedSetting.currency` · `prefix` · `suffix`

| | ฟิลด์ที่เป็นหยวน |
|---|---|
| โมดูล AC | **20 ฟิลด์ ใน 9 ตาราง** — ทั้งหมดเป็นตารางที่สร้างในรอบนี้ (AC-06 / AC-08 / AC-09) |
| โมดูล HR | **0 ฟิลด์** (ไม่ได้แตะ — นอกขอบเขต) |
| กราฟบนแดชบอร์ด 17 ตัว | **0** — กราฟดึงรูปแบบจากฟิลด์ ไม่ได้เก็บสัญลักษณ์ของตัวเอง ⇒ แก้ที่ฟิลด์แล้วกราฟตามเอง |

ตารางเก่าทั้งหมด (AC-00 … AC-05) **ไม่ได้รับผลกระทบ** เพราะใช้ฟิลด์ชนิด Number (type 6) ที่ไม่แสดงสัญลักษณ์สกุลเงินอยู่แล้ว

### ฟิลด์ที่แก้

| ตาราง | ฟิลด์ |
|---|---|
| งบทดลอง | `biz_tb_debit` · `biz_tb_credit` · `biz_tb_balance` |
| งบกำไรขาดทุน | `biz_is_amount` |
| งบแสดงฐานะการเงิน | `biz_bs_amount` |
| รอบการนำเข้าข้อมูล | `biz_ib_total_amount` |
| รายการข้อมูลที่รับเข้า | `biz_ir_debit` · `biz_ir_credit` |
| ทะเบียนสินทรัพย์ | `biz_ab_cost` · `biz_ab_salvage` · `biz_ab_accum_bf` · `biz_ab_accum_depr` · `biz_ab_nbv` |
| ตารางค่าเสื่อมราคา | `biz_ds_amount` · `biz_ds_accum_after` · `biz_ds_nbv_after` |

### วิธีแก้

```python
adv = dict(control['advancedSetting'])
adv['currency'] = '{"currencycode":"THB","symbol":"฿"}'
control['advancedSetting'] = adv
control['editAttrs'] = ['advancedSetting']
W.save_controls(S, wid, ctrls)
```

> `editAttrs` ต้องมี `advancedSetting` ไม่งั้น save ผ่านแต่ไม่มีอะไรเปลี่ยน · ทศนิยม (`dot`) และค่าที่บันทึกไว้เดิม **ไม่ถูกแตะ** — เปลี่ยนแค่การแสดงผล

### การตรวจ

1. อ่าน `advancedSetting.currency` กลับทั้ง 20 ฟิลด์ → THB ครบ ✓
2. สแกนซ้ำทั้งแอป 98 ตาราง → เหลือ ¥/￥/元/CNY **0 ฟิลด์** ✓
3. **เปิดหน้าจอจริงดูด้วยตา** (ตาม D-54) — `ทะเบียนสินทรัพย์` ขึ้น `฿ 58,000.00` / `฿ 1,150,000.00` · `งบทดลอง` ขึ้น `฿ 48,833.33` / `฿ 6,363,000.00` ✓

> 🔑 **บทเรียน D-63** — ฟิลด์ Currency ที่สร้างผ่าน API ได้ CNY เป็นค่าตั้งต้นเสมอ · **ต้องตั้ง `advancedSetting.currency` เป็น THB ตอนสร้างทุกครั้ง** ไม่งั้นจะไปโผล่ตอนลูกค้าเห็นหน้าจอ
