## 4. ข้อผิดพลาดที่เกิดระหว่างทำ และวิธีจับได้

### 4.1 โหลดข้อมูลจากไฟล์ที่ถูกเขียนทับ

ระหว่างเทียบว่า "ณ วันที่" ไหนให้การกระจายตัวดีที่สุด ผมรันสคริปต์ซ้ำหลายรอบ — **แต่ละรอบเขียนทับ `aging.json`**
รอบสุดท้ายคือ ณ 30/11/2026 แล้วสคริปต์โหลดกลับใช้ไฟล์นั้น ⇒ ได้ตารางที่ **ช่วงอายุมาจาก 30/11 แต่ฟิลด์ "ณ วันที่" เขียนว่า 30/09**

จับได้เพราะอ่านข้อมูลกลับมาสรุปหลังโหลด ไม่ได้เชื่อว่าโหลดสำเร็จ = ถูกต้อง
แก้โดยลบ 32 แถวทิ้ง สร้าง `aging.json` ใหม่ แล้วโหลดซ้ำ · ตรวจแล้วตรงกันทั้ง 3 ชั้น (สคริปต์ → ไฟล์ → เซิร์ฟเวอร์)

> 🔑 **D-65** — สคริปต์สำรวจที่เขียนทับไฟล์ผลลัพธ์เดียวกับที่สคริปต์โหลดใช้ = กับดัก · **ทุกงานที่โหลดข้อมูลต้องพิมพ์สรุปจากสิ่งที่อ่านกลับจากเซิร์ฟเวอร์ ไม่ใช่จากตัวแปรในหน่วยความจำ**

### 4.2 ย้ายตารางเข้ากลุ่มด้วย API ไม่ได้

`AppManagement/EditWorkSheetInfoForApp` (แก้ชื่อ/ไอคอนเท่านั้น) คืน `False` · `HomeApp/UpdateSectionChildSort` คืน `code 1` แต่ **ตารางไม่ขยับ** · `MoveAppItem` / `UpdateAppItemSection` / `MoveWorkSheetToSection` ทั้งหมด 404

⇒ ทางที่ได้ผลคือ **ลบตารางแล้วสร้างใหม่โดยส่ง `--section-id` เป็น id ของ "กลุ่ม" ตั้งแต่แรก** (กลุ่มคือ childSection — ต่อยอด D-52)

> 🔑 **D-66** — `hap worksheet create --section-id` รับ id ของกลุ่มได้ และเป็น**วิธีเดียวที่พบว่าจัดตารางเข้ากลุ่มได้จาก API** · ถ้าสร้างผิดที่แล้ว ต้องลบสร้างใหม่ ⇒ **ตรวจ section-id ให้ถูกก่อนสร้างเสมอ**

### 4.3 🔴 คำกล่าวอ้างเดิมเรื่องกราฟไม่ถูกต้อง

ในเอกสาร 28 §8 ผมเขียนว่า "ตรวจกราฟบนแดชบอร์ดทั้ง 17 ตัว — ไม่มีสัญลักษณ์หยวน" โดยใช้ `chart.get_chart(...)`
**ตรวจซ้ำแล้วพบว่า `get_chart` คืน template เปล่าเสมอ** (`name=''`, `reportType=None`, `yaxisList=[]`) ไม่ว่าจะส่งพารามิเตอร์แบบใด
⇒ การตรวจรอบนั้น **ไม่ได้ตรวจอะไรเลย** ข้อสรุปบังเอิญถูก แต่วิธีไม่มีน้ำหนัก

**ตรวจใหม่ด้วยตาบนหน้าจอจริง 7 ก.ย. 2569** — แดชบอร์ดบัญชีแสดง 6,188,966.67 / 3,020,256.68 / 2,018,890 / 2,191,729.7 · การ์ดและกราฟทุกตัวขึ้นตัวเลขล้วน ไม่มี ¥ ⇒ **ข้อสรุปเดิมถูกต้อง แต่ยืนยันด้วยหลักฐานใหม่**

> 🔑 **D-67** — `chart.get_chart` บน tenant นี้คืน template เปล่า **ไม่ใช่ config จริง** · ห้ามใช้เป็นหลักฐานว่ากราฟมีหรือไม่มีอะไร · ต่อยอด D-54 ที่ว่ากราฟต้องตรวจด้วยตา
